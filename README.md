Este é o site pessoal de **Leandro Jesse**, um desenvolvedor focado na orquestração de Inteligência Artificial para a criação de interfaces modernas, interativas e de alta fidelidade visual. O projeto foi concebido com uma mentalidade "Figma-first", garantindo que cada pixel e movimento de transição reflitam o estado da arte do design de interface atual.

## ✨ Características Principais

- **💎 Experiência Visual Marcante**: Design focado em Dark Mode com acentos Neon Cyan e tipografia robusta (Space Grotesk).
- **⚛️ Partículas Interativas**: Background vivo que reage à posição e ao raio de influência do cursor do mouse, ajustável pelo usuário.
- **⚡ Motion Design Avançado**: Uso extensivo de `framer-motion` para transições suaves, efeitos de parallax e botões magnéticos.
- **🎨 Estética Figma-to-Code**: Interface que utiliza grids, réguas e marcadores de componentes que remetem ao ambiente de design profissional.
- **🤖 Fluxo Assistido por IA**: Desenvolvimento otimizado através de prompts generativos para lógica e refinamento estético.
- **📱 Responsividade Extrema**: Experiência fluida adaptada para dispositivos móveis, tablets e desktops de alta resolução.

## 🛠️ Tech Stack

- **Core**: React 19 + TypeScript
- **Estilização**: Tailwind CSS para layout utilitário e responsivo.
- **Animações**: Framer Motion para orquestração de estados e scroll parallax.
- **Ícones**: Lucide React para um set de ícones moderno e leve.
- **Build Tool**: Vite para um ambiente de desenvolvimento ultra-rápido.
- **Integração**: Conexão com a API do GitHub para exibição dinâmica de repositórios.

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o **Node.js** instalado.
2. Clone o repositório:
   ```bash
   git clone https://github.com/leorecoa/leandro-jesse-portfolio.git
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 🧠 Conceito: "The Vision"

O projeto explora a ideia de que a tecnologia não é apenas uma ferramenta, mas uma extensão da criatividade humana. Através da união entre **Código Semântico** e **Inteligência Artificial**, o portfólio demonstra como interfaces podem ser "vivas" e centradas no usuário.
