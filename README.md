Portfólio pessoal desenvolvido para apresentar minha trajetória como desenvolvedor, meus projetos, stack técnica e formas de contato.

A aplicação foi construída com React, TypeScript, Vite, Tailwind CSS, Framer Motion e Lucide React. O foco do projeto é entregar uma interface responsiva, com boa organização visual, animações controladas e componentes separados por responsabilidade.

Visão geral

O projeto funciona como uma vitrine técnica para centralizar minha apresentação profissional e destacar projetos desenvolvidos no GitHub.

A interface possui navegação por seções, background interativo com partículas, tela inicial de carregamento, área de projetos, stack técnica e seção de contato.

Funcionalidades

- Interface responsiva para desktop e mobile
- Estrutura baseada em componentes reutilizáveis
- Seções dedicadas para apresentação, processo, projetos, stack e contato
- Background interativo com controle de área de influência do cursor
- Animações com Framer Motion
- Ícones com Lucide React
- Estilização com Tailwind CSS
- Build otimizado com Vite
- Deploy publicado na Vercel

Como executar

Clone o repositório:

git clone https://github.com/leorecoa/Portfolio.git

Entre na pasta do projeto:

cd Portfolio

Instale as dependências:

npm install

Inicie o ambiente de desenvolvimento:

npm run dev

Gere o build de produção:

npm run build

Visualize o build localmente:

npm run preview

Deploy

O projeto está publicado na Vercel:

https://portfolio-vert-alpha-h2mwblh056.vercel.app
